# StudentHub Portal 🎓

A centralized web application designed for students, faculty, and administration at Charotar University of Science and Technology (CHARUSAT). StudentHub simplifies academic communication, attendance tracking, study material distribution, course management, event hosting, and administrative moderation into a single platform.
